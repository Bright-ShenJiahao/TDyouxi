# 美术规范与出图提示词（给 Gemini）

## 统一规范
- **出图前先上传参考图**：`src/hall.png`（茅山主殿）、`src/tower.png`（符塔）、`src/map_cn.jpg`（地图）。
- 画风：2.5D 手绘卡通，粗深褐色描边，赛璐璐硬边明暗，饱和温暖的配色，中国民国乡野、林正英僵尸电影氛围。
- 视角：俯视约 45 度斜角，和符塔、主殿完全一致；光源在左上。
- 体量：塔和符塔一样矮胖敦实，Q 版、像玩具。
- 背景：**真正的透明 PNG**，不要画灰白格子，不要地面、阴影以外的任何背景，不要文字。
- 出完下载原图（不要截图），放进 `src/`，按下表命名，运行 `python3 src/build.py` 即自动替换占位图。

| 素材 | 文件名 |
|---|---|
| 雷法塔 | `src/tower_lei.png` |
| 朱砂炮塔 | `src/tower_pao.png` |
| 符网塔 | `src/tower_wang.png` |
| 英雄酒馆 | `src/tavern.png` |

> 换上酒馆图后，`src/js/hero.js` 的 `drawTavern` 需要改成画 `I.tavern`（任务卡 T6）。

## 开场白（每次新对话先发）
```
接下来为一款横屏塔防手游生成素材。请严格参考我上传的茅山主殿、符塔两张图：同一画风（2.5D 手绘卡通、粗深褐色描边、赛璐璐硬边明暗）、同一 45 度俯视视角、同一光源（左上）、同一描边粗细，像同一个美术画的同一套素材。只学画风，内容按我的描述原创。每张图都是真正的透明背景 PNG，不要灰白格子、不要地面和文字，建筑完整居中、四周留白。
```
